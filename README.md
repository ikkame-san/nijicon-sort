# 虹コン楽曲ソート

虹のコンキスタドールの好きな曲を選び、自分のランキングを作る非公式ファンサイトです。「デビルアンセムソート」を参考に作成しました。

## 起動

親フォルダーの「起動.cmd」を開き、http://127.0.0.1:4180 でグループを選べます。Node.js 20.9以上が必要です。画像は同梱済みなので、起動のために npm install は必要ありません。

このフォルダーだけで起動する場合:

```powershell
node scripts/serve.mjs
```

単独起動では http://127.0.0.1:4181 を開きます。ES Modulesを使うため、index.htmlの直接ダブルクリックでは起動できません。

## 機能

- 曲名検索、公開年の絞り込み、曲の追加、ランキング対象の選択
- 多言語版・リミックスの表示切替（初期値は両方オフ）。外すと該当曲の選択も解除
- 「メビウス・メモリー」原曲と18リミックスを収録。初期表示110曲、すべてオンで139曲。リミックスは公式が案内するGoogle Drive試聴へ移動
- 上位15曲・25曲・全曲、または任意の順位数を指定
- 2曲比較、3〜4曲の順番選択、30回分の戻る操作、途中保存と再開
- ジャケット入りPNGの保存と共有、結果リンク・テキストのコピー、Xへの共有
- 確認できた公式MV・ダンス・ライブ動画の表示。未対応曲はYouTube検索
- スマートフォン対応、独立したlocalStorageキー

## 曲目

2026-10-25に新曲を追加。139曲、公式動画81曲、リミックス試聴18曲。虹コン公式ディスコグラフィー48作品、TuneCore公式配信24作品、Apple Music配信、公式YouTubeプレイリストを照合しています。

再録、リマスター、予科生版、短縮版はまとめ、インスト・カラオケ・テレビサイズは除外しています。別言語、リミックス、アコースティックなどの別アレンジは別曲です。「やるっきゃない！」の年を含む正式タイトルは個別に掲載しています。DJ連続ミックス全体、コンサート名、個人のソロ曲は含めていません。

音源未確認で公式動画を確認できた「はじまるよっ！虹色サマー」「やるっきゃない！2025」も掲載しています。これらの年は公式動画の公開年で、ジャケットは音符表示です。ほかの曲の日付は確認できた収録作品の最も早い日付で、初披露日を保証するものではありません。見つからない曲はUIから追加できます。

曲別の根拠URLはsongs.jsのsources、ジャケットの元URLはartworkSource、動画の参照元はvideo.sourceに保持しています。公式ページ内の重複、誤記、全角半角の表記揺れを整理しています。「サイコタイプ」を配信表記の「サイコダイブ」に、「勝手に最高！デスティニー」を「勝手に最高！ディスティニー」に補正し、短く途切れた「トライアングル・ドリーマー」「ブランニューハッピーデイズ」を復元しています。

## 画像と保守

jackets内のWebPは256pxで同梱しています。画面もPNG保存も同一オリジンの画像を使います。音源・歌詞は同梱しません。カタログの手動更新はsongs.jsを編集し、既存のIDを維持してください。画像を再取得する場合のみ依存関係をインストールします。

```powershell
npm ci
node scripts/build-jackets.mjs
npm run check
npm test
```

静的ホスティングへはindex.html、app.js、engine.js、songs.js、jackets.js、catalog.js、styles.css、favicon.svg、jackets/を配置すれば動きます。

## 保存と共有

選択・途中結果・追加曲・名前はブラウザ内に保存します。両グループの保存キーは別です。共有リンクのURLフラグメントには順位、曲名、任意の名前、作成日、対象曲数が入ります。ローカル起動中のURLは他の端末から開けません。公開後は公開URLの結果リンクを共有できます。

本サイトは非公式で、各グループと関係各社とは関係ありません。

## 2026-10-10の追加

「集え！フロンティアーナ」を虹組の楽曲として追加。ベボガ！のアルバムBBG!（2017-12-19）収録、MOSAIC.WAV公式の楽曲提供記事と虹コン公式ブログで確認しています。通常曲として初期表示に含めます。確認できたYouTube検索結果は非公式の映像とMOSAIC.WAV本人版だったため、曲別映像には採用せずYouTube検索を表示しています。ジャケットは公式楽曲提供記事のBBG!画像を同梱しています。

## 2026-10-25の追加

「夢見心地♡ランデヴー」を通常曲として追加し、初期表示110曲・全139曲。公式告知の配信予定日2026-10-26を記録しています。公式サイト本文にある「ランデブー」は表記ゆれとして扱い、見出し・配信曲概要・ユーザー指定と一致する「ランデヴー」を採用。曲別公式YouTube動画は検索で未確認のため検索リンクを表示し、別曲の「パウダースノーランデブー」やニュース動画は割り当てません。基礎カタログの照合は2026-10-10で、今回の追加曲のみ追加確認しています。

[公式配信告知](https://2zicon.tokyo/information/2026au_release/) ／ [曲名付きジャケット掲載](https://popnroll.tv/articles/48068)

基礎データ再生成後はルートで `node scripts/add-nijicon-202610.mjs` を実行。ジャケットも取得する場合は `--cover` を付けます。
